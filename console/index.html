如何获取豆包网页版 Cookie？
1. 用电脑浏览器登录 https://www.doubao.com/chat/
2. 按 F12 打开开发者工具，切到「网络(Network)」面板
3. 在豆包输入框随便发一句话
4. 在请求列表找到 completion 请求，右键 → 复制 → 复制为 cURL (bash)
5. 从 cURL 里找到 --cookie '...' 一段，把引号内整串填进 .env 的 DOUBAO_COOKIE_1=（推荐含 sessionid、ttwid、uid_tt）
遇到 400 / 403 / user invalid 怎么办？
400/403（风控）：在浏览器任意一个 completion 请求的 URL 里复制真实的 msToken 和 a_bogus，填入 .env 的 DOUBAO_MS_TOKEN= 与 DOUBAO_A_BOGUS=。
user invalid：Cookie 已过期，重新登录豆包并更新 .env。
仍不行：换 IP，或改用官方方舟通道（ARK_API_KEY）兜底。
怎么配豆包官方 API（推荐，稳定）？
1. 前往 console.volcengine.com/ark 注册并实名
2. 开通需要的模型（lite 类每天有免费 token 额度）
3. 创建 API Key，填入 .env 的 ARK_API_KEY=
4. 模型名以方舟控制台「模型列表」为准，填入 ARK_MODEL=
怎么配 DeepSeek（免费）？
方式一（网页版，免 Key）：登录 chat.deepseek.com，F12 → 网络 → 发一句话 → 找 chat/completions 请求 → 复制为 cURL，取 --cookie '...' 整串填入 .env 的 DEEPSEEK_COOKIE_1=（会自动提取其中的 token）。
方式二（网页版 Token）：登录后 F12 → 任意请求头里的 Authorization: Bearer xxx，把 xxx 填入 DEEPSEEK_TOKEN=。
方式三（官方，按量计费）：在 platform.deepseek.com 创建 Key，填入 DEEPSEEK_API_KEY=（仅网页版不可用时的稳定兜底）。
怎么配通义千问 Qwen（免费额度）？
1. 前往 bailian.console.aliyun.com 登录（支付宝/淘宝账号即可）
2. 开通百炼，创建 API-KEY，填入 .env 的 QWEN_API_KEY=
3. 新用户赠送免费 token 额度，日常可用 qwen-turbo / qwen-plus
4. 客户端模型名填 qwen-turbo / qwen-plus / qwen-max / qwen-long

curl 快速测试

把 YOUR_KEY 换成你的凭据（服务端授权码 / Cookie / sessionid 均可）
curl -N http://127.0.0.1:5005/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_KEY" \
  -d '{"model":"doubao-web","messages":[{"role":"user","content":"你好"}],"stream":true}'

Python（OpenAI SDK）

from openai import OpenAI
client = OpenAI(
    api_key="YOUR_KEY",
    base_url="http://127.0.0.1:5005/v1",
)
r = client.chat.completions.create(
    model="doubao-web",
    messages=[{"role":"user","content":"你好"}],
)
print(r.choices[0].message.content)

认证两种模式

直传凭据
Authorization 直接填你的 Cookie / sessionid，网关用它调豆包
服务端账号池
.env 设 AUTHORIZATION=你的授权码，客户端用授权码当 Key，网关自动从账号池轮询
模型路由
doubao-web / doubao-free → 网页版；doubao-*（配了 ARK key）→ 方舟；deepseek-* / kimi-* → 兼容上游；其它 → 默认网页版
